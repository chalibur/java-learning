### 接口
>接口：
>
>就是一个规则，而且是独立于继承体系之外的规则（可以理解成干爹）
> 子类必须按照接口的格式严格书写
>
> 格式：interface
```java
public class leiming implements  jiekou{}
```
>使用：接口和类之间是实现关系，可以通过implements关键字实现
>
> 注意：
>
> 1.接口不能实例化
>
> 2.接口的子类（实现类），要么重写接口中的所有抽象方法，妖魔，实现类是一个抽象方法
>
> 3.一个类可以实现多个接口，也可以在继承一个类的时候，实现多个接口
### 接口里面成员的特点
>1.接口里面的成员变量：只能说是常量，默认是public static final的
> 
> 2.构造方法：接口里面不能有构造方法
> 
> 3.只能是抽象方法
> 
> 
### 接口和类之间的关系
> 类和类之间的关系：
> 
> 继承关系，只能单继承，不能多继承，但是可以多层继承
> 
> 类和接口的关系：
> 
> 实现关系，可以单实线，也可以多实现，还可以在继承一个类的同时实现多个接口
> 
> 接口和接口的关系：
>
> 继承关系，可以单继承，也可以多继承
> >如果有一个接口继承了多个接口，那这个接口的实现类就需要把多个接口中的抽象方法全部重写
> 如果在重写的时候出现的多个相同的抽象方法，重写一次就可以
> 
### JDk8之后接口新增的方法
#### 默认方法
> 接口里面可以有默认方法，格式：default
    
```java
public default void function(){
     System.out.println("接口中新增的默认方法");}
```
>     //接口中的新增的带有方法体的默认方法，不用强制重写
> 
#### 静态方法
> 接口里面可以有静态方法，格式：static
```java
public static void function(){
     System.out.println("接口中新增的静态方法");}
```
>     //接口中的新增的带有方法体的静态方法，不用强制重写
> 
> //只能通过接口名进行调用，不能通过类名或者对象名进行调用
> 
#### 私有方法
> 接口里面可以有私有方法，格式：private
```java
public private void function(){
     System.out.println("接口中新增的私有方法");}
```
//为了抽取接口中默认方法和静态代码中的重复代码而存在的
